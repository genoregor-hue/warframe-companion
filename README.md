# Warframe Companion

Локальное веб-приложение для Warframe: **планировщик фарма**, **калькулятор билдов с автосборкой топ-билда** и **цены warframe.market**. Новые функции подключаются как модули, ядро при этом не меняется.

Это внешний инструмент на открытых данных. Он **не читает и не меняет память клиента, не перехватывает трафик и не автоматизирует ввод в игре**. С игрой приложение не взаимодействует вообще, поэтому античит его не касается.

## Запуск

### Для игроков: один файл

1. Скачайте `WarframeCompanion.exe` со страницы **Releases** этого репозитория.
2. Запустите его двойным щелчком. Откроется окно консоли, а приложение само откроется в браузере.
3. Пока пользуетесь приложением, окно консоли не закрывайте: закрыли — приложение остановилось.

Устанавливать ничего не нужно. При первом запуске приложение скачивает официальные данные (~15 МБ) и хранит их в `%LOCALAPPDATA%\WarframeCompanion`, поэтому `.exe` можно держать в любой папке. Если порт 5178 занят, берётся следующий свободный.

Файл не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».

### Для разработчиков

Нужен Node.js 20+ (проверено на 24.14).

```bash
npm install
npm start
```

`npm start` запускает режим разработки с автообновлением на <http://127.0.0.1:5178>, кеш данных лежит в `data/cache/`. Кнопка **«Обновить данные»** в шапке перекачивает Public Export, таблицы дропа и список предметов маркета. Состояние мира обновляется само раз в 2 минуты.

```bash
npm test              # все тесты
npm run test:coverage # тесты + покрытие (пороги 80% строк/функций)
npm run typecheck     # проверка типов
npm run build:exe     # собрать release/WarframeCompanion.exe
```

`build:exe` собирает интерфейс в `dist/`, сервер — в один файл, и упаковывает их вместе с Node.js в исполняемый файл (Node.js Single Executable Application). Получается файл для той ОС, на которой идёт сборка. Переменная окружения `WFC_NO_BROWSER=1` запускает `.exe` без открытия браузера.

## Что умеет

### Фарм

- Цель: варфрейм, оружие (в том числе Prime), часть, мод, мистификатор, реликвия или ресурс.
- Маршрут: чертёж и части, затем реликвии с шансом по каждой очистке, затем миссии и ротации, где реликвия выпадает, и прямой дроп. Для каждой строки показано ожидаемое число прогонов и сколько нужно для 90% уверенности.
- Реликвии в хранилище помечаются. Если реликвия есть у Варзии, это видно сразу.
- Текущие разрывы Бездны нужного уровня (со Стальным путём и временем до конца), а также вторжения и события, которые дают нужную часть.
- Прямо в карточке части — цена на warframe.market.

### Билды

- Две панели (A и B) и таблица сравнения: 8 слотов, эксилус, аура (у варфреймов), полярности, ранги, вместимость с реактором или катализатором, мистификаторы.
- Оружие: урон по типам с комбинацией элементов в порядке модов, крит (включая оранжевые и красные), статус, мультивыстрел, скорострельность, магазин, перезарядка, DPS очередью и с перезарядкой, статусов в секунду, урон по фракциям.
- Варфрейм: сила, длительность, дальность, эффективность (с игровыми ограничениями), здоровье, щиты, броня, энергия, снижение урона и эффективное здоровье.
- **«Собрать топ-билд»** — оптимизатор подбирает лучшие моды под цель: DPS, DPS с перезарядкой, статус или веса статов варфрейма. Можно потребовать конкретный элемент (например, «Вирус»). Учитываются вместимость, полярности и правило «один мод из семейства» (Primed, Archon, Umbral и Amalgam заменяют базовый мод).
- **«Улучшить текущий»** — оптимизация начинается от сборки в панели. Так можно взять топ-сборку с сайта и посмотреть, что в ней заменить.
- **Мои моды.** Моды можно добавить со скриншота, вставить из буфера (Ctrl+V), вставить текстом или включить **«Смотреть экран»**: вы выбираете окно игры в диалоге браузера, листаете коллекцию, а приложение распознаёт кадры (Tesseract.js, локально, русский и английский). После этого оптимизатор:
  - с галочкой «Только мои моды» собирает билд только из того, что у вас есть;
  - без неё собирает топ-билд и показывает недостающие моды с ценой и продавцами на warframe.market.
- **Импорт сборок с overframe.gg и других сайтов:** скриншот или скопированный список модов со страницы сборки попадает в панель A или B. Сайт автоматически не опрашивается.
- **Обучение на мете.** Сборки, отмеченные как «топ-сборка», попадают в локальную библиотеку. Для модов, эффект которых формулы не моделируют (Condition Overload, Hunter Munitions и подобные), оптимизатор добавляет небольшой бонус пропорционально тому, как часто их ставят в импортированных сборках. Галочка «Учитывать мету» включает этот бонус.

### Маркет

Поиск по всем торгуемым предметам. Показываются продавцы в игре, на сайте и офлайн, цена, ранг и количество. Кнопка **«Купить: скопировать сообщение»** кладёт в буфер стандартное сообщение warframe.market:

```
/w Ник Hi! I want to buy: "Serration (rank 10)" for 35 platinum. (warframe.market)
```

Сделку вы проводите сами в игре: приложение ничего не покупает и не пишет за вас.

## Источники данных

| Что | Откуда |
|---|---|
| Предметы, моды, оружие, варфреймы, реликвии, рецепты, узлы | Warframe Public Export: `content.warframe.com/PublicExport/index_{en,ru}.txt.lzma` → `Manifest/…` |
| Шансы выпадения | Официальные таблицы дропа: `warframe.com/droptables` |
| Разрывы, вторжения, события, Варзия | `api.warframestat.us/pc`; если он недоступен — официальный `api.warframe.com/cdn/worldState.php` |
| Цены | `api.warframe.market/v2` (не чаще ~3 запросов в секунду, ответы кешируются) |

## Стек и почему он

**Vite + TypeScript, без UI-фреймворка, плюс встроенный в dev-сервер Vite маленький Node API.**

- Браузер не может напрямую ходить на content.warframe.com и warframe.market (CORS), а LZMA-индекс удобнее распаковывать на сервере. Поэтому данные скачивает, кеширует на диск и раздаёт локальный сервер (`server/`). Он встроен в Vite как плагин: одна команда `npm start`, отдельный бэкенд не нужен.
- Расчётная логика написана чистыми функциями на TypeScript и покрыта тестами Vitest. Интерфейс — тонкий слой на DOM.
- Модули ищутся автоматически через `import.meta.glob`, поэтому новая папка сразу становится новой вкладкой.

## Архитектура

```
server/                 локальный API
  plugin.ts             dev-режим: /api внутри Vite, подхватывает src/modules/*/server.ts
  standalone.ts         точка входа .exe: раздаёт собранный интерфейс и /api из одного процесса
  api.ts, app.ts        общий обработчик /api и сборка хаба источников
  sources.ts            хаб источников: кеш, TTL, «протухшие» данные при ошибке, параметрические id
  coreSources.ts        Public Export, каталог, таблицы дропа, worldstate
  publicExport.ts       LZMA-индекс → manifest
src/
  core/                 ядро: реестр модулей, контекст, слой данных клиента, события, сервисы, оболочка
  data/                 чистые функции: каталог из Public Export, парсер таблиц дропа, нормализация worldstate
  modules/
    farm-planner/       вкладка «Фарм»
    build-calc/         вкладка «Билды» (logic/ — формулы, оптимизатор, OCR-сопоставление, обучение)
    market/             вкладка «Маркет» + сервис market.prices для других модулей
```

Что ядро даёт каждому модулю (`ModuleContext`):

- `data.source(id)` — любой источник с локальным кешем: `catalog`, `droptables`, `worldstate`, `export:ExportWeapons:ru`, а также источники модулей;
- `events` — шина событий: `data:refreshed`, `worldstate:updated` (раз в 2 минуты);
- `services` — возможности, которые модули дают друг другу: например, `market.prices`;
- `storage` — localStorage в пространстве имён модуля;
- `navigate(route)` — переход на другую вкладку.

## Как добавить модуль

1. Создайте папку `src/modules/<id>/` и в ней `index.ts`:

   ```ts
   import { defineModule } from '../../core/registry';
   import { h, replace } from '../../core/dom';
   import type { WorldState } from '../../data/worldstate';

   export default defineModule({
     id: 'alerts',               // a-z, 0-9, дефис; это же маршрут #/alerts
     title: 'Оповещения',
     icon: 'spark',              // имя иконки из src/core/icons.ts
     order: 40,                  // место вкладки
     setup(core) {
       // Выполняется при старте для всех модулей, даже если вкладка не открыта.
       core.events.on<WorldState>('worldstate:updated', (ws) => {
         // например, отправить уведомление о разрыве Axi со Стальным путём
       });
     },
     mount(root, ctx) {
       replace(root, h('h1', {}, 'Оповещения'));
       return () => { /* снять таймеры и подписки */ };
     },
   });
   ```

   Перезапускать ничего не нужно: вкладка появится сама.

2. Если модулю нужны внешние данные (например, Telegram Bot API или Discord webhook), положите рядом `server.ts`. Его источники подключатся автоматически:

   ```ts
   import { defineSource } from '../../../server/sources';
   import { fetchJson } from '../../../server/http';

   export const sources = [
     defineSource({ id: 'alerts:config', title: 'Оповещения', ttlMs: 60_000, load: async () => ({ ok: true }) }),
     // параметрический источник: ctx.data.source('alerts:node:SolNode1')
     defineSource({ id: 'alerts:node:*', idPattern: /^alerts:node:(\w+)$/, title: 'Узел', ttlMs: 60_000,
       load: async (_ctx, id) => fetchJson(`https://example.invalid/${id}`) }),
   ];
   ```

   Секреты (токен бота и т.п.) читайте из переменных окружения на сервере. В клиентский код и в репозиторий их не кладите.

3. Чтобы поделиться возможностью с другими модулями, опишите контракт в `contract.ts`, а в `setup` вызовите `core.services.provide('имя', сервис)`. Пример — `src/modules/market/contract.ts`. Потребители всегда проверяют сервис на `undefined`, потому что модуль могут удалить.

4. Логику держите в `logic/` чистыми функциями с тестами `*.test.ts` рядом: их подхватит `npm test`.

## Допущения и ограничения

- Статы варфрейма на 30 ранге: +100 к здоровью и щитам и ×1,5 к энергии от значений Public Export (`RANK30` в `frameCalc.ts`).
- Эффективное здоровье варфрейма = здоровье × (1 + броня/300) + щиты. Щитовой гейтинг не моделируется.
- **Цель для оружия.** Снижение урона бронёй = броня / (броня + 300), не больше 90%; чистый урон броню игнорирует. Уязвимость даёт ×1,5, стойкость ×0,5. Пресеты фракций (Гринир: удар и коррозия; Корпус: пронзание и магнит; Заражённые: разрез и огонь) взяты из знаний об игре, а не из официальных данных: их нет в Public Export. Дополнительное снятие брони способностями задаётся полем «снято брони, %».
- **Эффекты статусов** (галочка «Учитывать эффекты статусов», `STATUS_RULES` в `statusEffects.ts`). Модель установившегося состояния: срабатывания статусов в секунду делятся по долям урона, на враге держится min(частота × длительность, максимум) стаков. Вирус: +100% урона за первый стак и +25% за следующие, до +325% (6 с, 10 стаков); коррозия: −26% брони и −6% за следующие стаки, до −80% (8 с); огонь: −50% брони, пока висит, и урон со временем 50% × 6 тиков; кровотечение (разрез): 35% × 6 тиков сквозь броню; токсин: 50% × 6 тиков. Урон тиков считается от урона попадания с учётом крита. Числа — из знаний об игре, официальных данных по статусам нет; вирус считается по здоровью (щиты не моделируются), электричество, газ и магнит пока не дают эффектов.
- **Осколки архонта** (`SHARD_OPTIONS` в `frameCalc.ts`): Красный +10% силы или длительности, Лазурный +150 к здоровью, щитам или броне, +50 к энергии; тауфордж ×1,5. Значения из знаний об игре: в официальном экспорте у осколков нет статов. Бонусы к здоровью, щитам и броне прибавляются после модов.
- **Бонусный элемент Кувы/Тенет** входит в базовый урон как врождённый элемент: от него считаются и моды на урон, и моды на элементы.
- **Ривен** вводится текстом по-английски (как на карточке), разбирается теми же правилами, что и моды, и занимает один из 8 слотов.
- **Комбо и статусы.** Моды «stacks with / per Combo Multiplier» дают значение × (множитель − 1), моды «per Status Type affecting the target» — значение × число статусов. Оба числа задаются в настройках цели.
- Строки модов, которые формулы не понимают, не угадываются, а выводятся под статами: «Не моделируется в расчёте: …».
- Скрытые служебные варианты модов из Public Export (учебные Beginner/Intermediate и «Expert» без приставки Primed) из каталога исключены.
- Взаимоисключающие моды определяются по названию (Primed, Archon, Umbral, Amalgam). Galvanized-моды ставятся вместе с базовыми, как в игре.
- Распознавание текста при первом использовании скачивает языковые данные Tesseract (~20 МБ) с CDN jsDelivr. Само распознавание идёт локально в браузере.
- «Обучение» — частотная статистика по импортированным вами сборкам, а не нейросеть. Сбросить её можно кнопкой «Сбросить обучение».
